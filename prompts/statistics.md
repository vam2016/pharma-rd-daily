# 临床试验统计方法精选 · 任务规范 v2

执行 `prompts/editorial.md` 的共同规范，使用 `templates/statistics.md`。

## 纳入与范围

主题是临床研究生物统计方法的进展。通常检索运行前 7 天，以实际截止时间为准。优先有实质新意的方法论文、正式方法学报告、经核验的指南更新，以及能揭示设计问题的公开案例。案例必须标为“设计案例”，不能冒充新的方法理论。

方法专题是索引而非配额：估计目标、缺失数据、期中与序贯设计、贝叶斯与早期设计、样本量、因果与外部对照、生存与纵向分析，以及其他方法。不强行覆盖所有专题；只给实质展开的内容添加 `_data/topics.yml` 中的 `topics` ID。

## 每项组织

1. 中文问题导向标题、完整英文名称、日期、来源类型、阅读范围。
2. **解决什么问题**：现有方法的限制与本文新增贡献。
3. **方法与依据**：估计目标/决策目标、识别或模型假设、估计/推断方法、比较基准。区分理论、模拟与真实数据证据。
4. **适用边界**：适用人群/设计、偏离假设的风险、有限样本与计算代价、未能核验的部分。只读摘要时不写仿佛复现过的推导或参数。
5. **研发与设计启示**：可能改变的问题定义、证据整合、数据采集、试验设计或决策；明确应用仍需何种验证。不要每篇强制总结 Protocol/SAP 影响。
6. 原始来源、可用代码/补充材料链接（仅在实际找到且核验后提供）。

本期末尾提炼跨论文的研究方向和待验证问题。指南跟踪只报告已核实状态，不把计划里程碑当作新指南。

发布至 `_posts/statistics/YYYY-MM-DD-statistical-methods.md`；`section: statistics`、`format: research_digest`、稳定 URL `/statistics/YYYY-MM-DD/`。`week` 对应实际检索窗口，`topics` 仅使用固定 ID。
